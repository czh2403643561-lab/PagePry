# PagePry

- 项目用途：通过 AI API 增强网页信息采集能力，帮助后续开发使用的 Codex 获得更完整、准确、实用的页面证据。
- 当前实现：Chrome 扩展提供 Xiaomi MiMo-V2.6-Flash API Key 设置、独立连接测试与本机保存；用户点击“分析当前页面”后，可将限长页面证据发送给 MiMo 并在弹窗显示整理结果。
- 密钥存储：使用扩展本地存储，不使用同步存储；密钥不写入源码、日志或导出文件。
- 当前阶段：API 配置已在独立测试浏览器通过真实连接与保存重开验证；点击分析页面证据的链路已在公开 Apple MacBook Air 产品页完成真实浏览器验证，返回字段与页面文字相符，但不代表通用网页解析已验收。
- 页面分析范围：仅在用户主动点击后读取当前标签页的标题、去除查询参数的网址、描述、部分标题/表格摘要和最多 9,000 字可见文字；这些页面内容会发送到小米 MiMo API，可能产生用量费用。请勿在敏感页面使用。
- 运行说明：在 Chrome 扩展页面开启开发者模式并加载本项目目录，再从 PagePry 图标打开设置。
