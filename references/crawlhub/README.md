# CrawlHub 页面解析参考

本目录保留原始参考文件，本文件本身不直接运行；PagePry 的 `sampler.js` 已从中抽取并调整手动采样函数，独立测试浏览器已验证多元素采样和导出。

## 文件与解析能力

- `analyzer.js`：CrawlHub 原始完整文件，按字节原样复制。页面结构扫描从第 47 行开始；第 3 行识别滚动容器；第 354 行开始通用表格／列表解析；第 810 行根据候选元素选择滚动容器；第 3584 行开始网络观察器；第 3676 行开始手动元素采样。
- 文件还包含 CrawlHub 的其他采集与界面代码；保留整个原文件以保持原始上下文，本目录不引入 CrawlHub 的其他项目文件。

来源：本地 CrawlHub 仓库中的 `analyzer.js`，源仓库提交 `b87bde7`。源文件工作区未修改。SHA-256：`152717E95F4966C81F2C27DB5EF67159D82AF3B6A4626828C5C0A695CB55CCEA`。

## 依赖与限制

- 未发现 npm 依赖清单、外部模块导入或第三方代码标记；核心解析依赖浏览器 DOM API，在页面上下文中读取当前已加载内容。
- 原扩展的脚本注入和完整面板还依赖 CrawlHub 的 `manifest.json`、`popup.js`、`content.js` 等文件；这些入口和存储桥未复制，因此此目录不是可运行扩展。
- 扫描只覆盖当前页面已加载的 DOM，并受源码中的数量上限影响。网络观察器须手动启动，只记录之后 Fetch/XHR 请求的脱敏元信息，不读取请求或响应正文。
- CrawlHub 根目录未找到 LICENSE/NOTICE，`analyzer.js` 未见许可证声明。本次未为副本添加或暗示任何开源许可证。
