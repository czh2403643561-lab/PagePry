# 公开商品页面采集评估

测试时间：2026-10-29（北京时间）；PagePry 提交 `c707129`，独立测试浏览器，SingleFile 已安装并授权。以下均为游客页面当时看到的内容，商品及价格会变化。本次使用“分析与报告”导出，没有调用 MiMo。

## 结论

资料包**可以作为 Codex 开发浏览器插件的页面证据**：能查看页面文字、部分表格、人工选中的元素及其祖先和相邻元素，并可在离线 HTML 中检查不少 DOM 与图片。它不能直接作为可安装插件，也不能独立证明动态交互、全部商品字段或选择器长期有效；仍需编写插件代码并在真实页面验证。

## 实测结果

四次均通过插件入口手动采样、点击“分析与报告”、下载 ZIP，并用 ZIP 校验和读取文件。四个包均包含 `README.md`、`report.md`、`data/page.json`、`data/samples.json` 和 `snapshot/page.html`，状态均显示结构、采样和快照成功。快照属于经过 PagePry 清理的 SingleFile HTML。

## 资料包对开发的价值和限制

- `report.md` 适合快速理解页面和人工样本；`data/page.json` 包含标题、描述、标题层级、有限表格和最多 9,000 字符的可见文字；`data/samples.json` 包含标签、文本、选择器、XPath、祖先及相邻元素。上述信息可用来设计提取规则和测试样例。
- `snapshot/page.html` 可以本地打开，保留了本次页面的大量结构和图片。实测 1688 首页一个样本的 XPath 在实时页面和快照中均指向原商品名称。但快照移除了脚本、按钮、表单、框架和部分属性；它不是完整的可交互页面，不能用来验证登录态、接口请求、滚动加载、弹窗或按钮交互。
- 选择器需要重新验证：Logitech 商品名样本的 CSS 选择器包含未转义的冒号，浏览器判断为无效；1688 首页商品名样本的 CSS 选择器匹配 67 项。相应 XPath 在当时的实时页面可定位，但不保证页面变化后仍有效。
- Anker 的价格样本实际落在按钮内；快照清理按钮后，该样本的 XPath 在快照中找不到，虽然页面其他位置仍有该价格。因此，样本定位与脱敏快照的结构并不总是一致。
- 网址查询参数会被移除，能减少凭据暴露，但一些原本用于搜索、规格或商品跳转的参数也会丢失。页面未加载的内容、嵌入框架、隐藏内容及图片中的文字不保证出现在结构化数据中。
- 自动脱敏只能识别部分常见形式。资料包可能仍含敏感信息或第三方页面内容，分享前需检查。本报告仅提交结论，不上传原始 ZIP 或网页快照。

## 建议的后续优先级

1. 修正 CSS 选择器转义和唯一性，并在导出时标明定位是否有效；避免把不完整的价格片段当作完整价格。
2. 针对重复商品卡片建立结构化字段及来源关联，明确哪些内容被截断、未加载或需要交互。
3. 改善弹窗、按钮和快照清理后的定位关系，同时保留必要的隐私保护；后续方案需在真实目标页面验收。
